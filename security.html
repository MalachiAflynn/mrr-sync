Security

How your data is kept

What the app can reach, how it keeps keys and tokens, and how to tell us about a problem.

Draft: review before launchThis page was written from what the app does today. It has not had a legal review yet.

Only the access it needs

  • Stripe: a restricted key that can only read your account, customers, subscriptions, invoices, charges, prices, products and coupons. Its one write permission is webhook endpoints, so the app can add the single endpoint that tells it about changes. It never creates, changes or deletes customers, charges, refunds or subscriptions. Standard secret keys are refused.
  • HubSpot: the 6 permissions listed on the Install page. The app writes only its nine properties, a new contact when no contact matches, and timeline notes.

Encryption

  • HubSpot access and refresh tokens, your Stripe restricted key and the Stripe webhook signing secret are encrypted with AES-256-GCM before they are stored. Each carries the version of the key that encrypted it, so keys can be rotated.
  • The encryption keys live only in the server's environment settings, never in the database or the code.
  • After saving, the Stripe key is never shown again, only its last four characters.
  • The app is served over HTTPS (TLS) only. It refuses to start in production with a plain http address, and it tells browsers to use HTTPS every time (HSTS).

Signing in

The dashboard uses Sign in with HubSpot, so there is no separate password to leak. The session lives on the server; its cookie cannot be read by scripts and is only sent over HTTPS. A session ends after 7 days without a visit.

How long it is kept

  • Stripe event contents are emptied after 30 days, and the event records deleted after 90.
  • The sync log keeps the newest 1,000 lines per account.
  • After you uninstall, everything the app holds for your account is deleted within 30 days. Delete my data in Settings deletes it right away.

Logs

Server logs redact tokens, keys, secrets, cookies, authorization headers and email fields before they are written.

Certifications

We hold no SOC 2, ISO 27001 or other security certification. This page describes what the app actually does instead.

Report a vulnerability

Email support@example.com with Security in the subject. We reply within one business day. Please test only against an account of your own, and never read or change another customer's data or try to take the service down.
